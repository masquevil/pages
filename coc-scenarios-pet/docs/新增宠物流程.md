# 新宠物图集：生成、裁切、接入绘本

## 先明确任务边界

收到用户的一小段形象描述时，先确定是替换现有 `dog`、`cat`、`bird` 的图集，还是新增第四种宠物。新增物种需要确定稳定的英文小写标识 `<pet>` 和中文称呼；不明确就先询问。保存用户原始描述，不能擅自套用狗猫的纯色或鸟的花色，也不要用历史缺陷图作参考。猫狗目前选用的纯色提示词在 `refs/prompts/pet-story-poses-text-only-solid-v1.json`；当前鸟的形象是黄色圆身、橄榄绿翅膀和尾巴、橙色脸颊、短珊瑚色喙及弯曲头羽。其他动物须以用户的新描述为准。

**现有工具限制：** `scripts/publish_selected_pet_poses.py` 固定读取 `poses/dog-01.png`、`cat-01.png`、`bird-01.png`，一次发布三种各 12 张，且要求旧素材存在。`tests/test_selected_pet_poses.py` 与 `tests/book.test.cjs` 也固定按三物种检查。新增物种目前**没有一键接入命令**；不可直接运行旧发布器声称已接入。

## A. 提示词与候选图集

生成一张 **4 列 × 3 行、12 个动作**的透明完整图集，同一张图集内角色形象一致；成人向克制童话、简洁轮廓、平涂、中性表情，无场景、文字、毛发纹理或褶皱。站姿要画清可见的支撑腿与爪；鸟及其他动物按真实肢体结构描述。避免在提示词中反复提及历史缺陷（如“第五条腿”）。动作顺序固定：

| | 第一列 | 第二列 | 第三列 | 第四列 |
| --- | --- | --- | --- | --- |
| 第一行 | 封面坐姿背影 | 01 仰躺 | 02 蜷缩（03 桶旁复用） | 03 门口伸爪／足 |
| 第二行 | 03 窗前背影 | 04 悬浮 | 05 向右行进 | 06 坐姿，仅此格少量临时灰尘 |
| 第三行 | 07 衰老回望 | 08 衰老悬浮、出现变化 | 09 衰老背影、保留变化 | 10 衰老背影向右、保留变化 |

狗猫后期变化为小翅膀，当前鸟为淡紫头羽；新物种效果由其设定决定。保存**实际发送模型的完整提示词**到 `refs/prompts/`，以便后续复现。使用安装的 `image-gen` skill 做**纯文生图**（`--mode text`），不上传其他动物、旧图集或照片。以下命令中的尖括号与提示词路径是示意，执行前替换并确认输出文件不存在：

```sh
node "$HOME/.agents/skills/image-gen/scripts/node/image-gen.js" \
  --mode text --model gpt-image-2.5-sunburst --n 1 --size 1536x1536 \
  --prompt "$(cat /绝对路径/本次完整提示词.txt)" \
  --out "/Users/soulran/code/pages/coc-scenarios-pet/picture-book/assets/pets/poses/<pet>-01.png"
```

候选未确定时先另存为 `<pet>-02.png`、`<pet>-03.png` 等，**不要覆盖用户已选的 `01`**。密钥只用环境变量或用户级配置，不写入项目。接口失败就报告失败，不用旧图片充数。检查候选是否能读取、是否为 PNG 且带 alpha：

```sh
python3 -c 'from PIL import Image; p="/绝对路径/候选.png"; im=Image.open(p); im.verify(); im=Image.open(p); print(im.format, im.mode, im.size, im.getchannel("A").getextrema())'
```

带 alpha 无需重新抠白底、调色；文件格式检查**不等于**动作正确。将完整图集交用户检查角色、顺序、肢体、格线与画风，用户选定后再裁切。需要更换选定 `01` 时先保留旧版副本。

## B. 保留原始 alpha 裁切

`scripts/publish_selected_pet_poses.py` 的 `extract_sheet()` 以格子确定动作序号，但按透明 alpha 连通区域取完整角色，避免直接沿格线切掉脚和尾巴；`scripts/pet_slot.py` 的 `fit_slot()` 缩放至现用 `290×310` RGBA 透明槽。要求每格主体可独立识别；如格线粘连、身体断开或跨格粘连，提取可能拒绝或裁断，必须先在临时目录检查 **12 张裁切图**，不能只依赖 PNG 解码与单元测试。以下只生成待检查的临时文件，不修改页面素材；运行前把 `animal` 和 `source` 改成选定图集：

```sh
PYTHONPATH=scripts python3 - <<'PY'
from pathlib import Path
from tempfile import mkdtemp
from PIL import Image
from publish_selected_pet_poses import extract_sheet

animal = 'dog'
source = Path('picture-book/assets/pets/poses/dog-01.png')
output = Path(mkdtemp(prefix=f'{animal}-pose-review-'))
with Image.open(source) as sheet:
    sprites = extract_sheet(sheet, animal)
for name, sprite in sprites.items():
    sprite.save(output / name)
print(f'{len(sprites)} 张待检查切片：{output}')
PY
```

### 替换已有三种宠物

保持 `poses/dog-01.png`、`cat-01.png`、`bird-01.png` 为各自已确认图集。脚本**会重发全部三种**，因此替换其中一种也要确认其余两张仍获认可。项目根目录执行：

```sh
python3 tests/test_selected_pet_poses.py
python3 scripts/publish_selected_pet_poses.py
```

发布脚本把 36 张旧页面切片备份到系统临时目录 `pet-previous-live-*` 并打印路径。若希望只发布一个物种，须先扩展脚本和测试，不能误以为它目前支持单物种。临时备份并非长期存档。

### 新增第四种（或更多）

不能直接使用固定三物种的发布入口。以 `extract_sheet(image, '<pet>')` 验证新图集 12 格，扩展脚本使其能选择物种、处理尚不存在的目标目录、完整暂存并备份后发布；检查裁切后的所有结果。发布到 `picture-book/assets/pets/<pet>/`，基础文件名是 `healthy-back.png`、`healthy-belly-up.png`、`healthy-curl.png`、`healthy-reach.png`、`healthy-window-back.png`、`healthy-float.png`、`healthy-travel.png`、`dirty-sit.png`、`old-look.png` 以及 08–10 对应的 `old-float-*`、`old-back-*`、`old-back-*-right.png`。狗使用 `winged`，猫鸟使用 `magic`；新物种的后缀必须与 JS 映射一致。

接入清单：

1. `picture-book/js/book.js`：在 `Book.pets` 注册 `<pet>` 与中文称呼；检查专属文案选择、`petAsset()` 的后期变化文件映射与 `Book.assets()` 的完整路径。不要把新角色错误归入狗或鸟的特殊分支。
2. `picture-book/js/pet-layout.js` 的 `PetLayout`：新增 `cover`、01–10 的位置／宽度配置；03 页必须有门口、窗前、桶旁三个槽位。按真实图集预览调大小、翻转，预览与打印使用同一配置。
3. 如果通用文案不适合该动物，在 `docs/绘本文本.md` 添加专属覆盖段落，并扩展 `scripts/build_text.py` 的解析、`book.js` 的选择逻辑；运行 `python3 scripts/build_text.py` 更新 `picture-book/js/data.js`。通用文案合适则不改。
4. `picture-book/js/app.js` 会根据 `Book.pets` 自动创建顶部按钮，并取 `<pet>/healthy-back.png` 为缩略图；确认对应资源存在。必要时更新 `picture-book/index.html` 的脚本版本号避免缓存。
5. 扩展 `tests/book.test.cjs`、`tests/test_selected_pet_poses.py` 的物种、目录和 12 张切片断言，并在浏览器回归中切换新增宠物；目前测试名单写死三种。

python3 scripts/build_text.py --check
git diff --check
python3 -m http.server 8765 --bind 127.0.0.1 --directory /Users/soulran/code/pages/coc-scenarios-pet/picture-book

在 http://127.0.0.1:8765/ 检查封面、01、03 三槽、06 脏旧及 08–10 效果；检查无破图、无裁断，预览与打印一致；当前页输出 1 张、整本 7 张 A4。发现问题时按终端打印的备份路径回退；**格式与自动测试通过不代表用户认可新造型**。
